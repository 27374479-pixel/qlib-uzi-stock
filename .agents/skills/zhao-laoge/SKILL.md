# 赵老哥：超短选股要诀

用于把“只做龙头、只做主升、只做新题材”转成可验证的选股与退出规则。材料来自用户提供的《48位游资悟道心得语录》第四章，是公开二次整理，并非本人完整策略披露。

## 核心边界

- 新题材优先于旧题材，但“新”不是买入理由；必须有故事/催化、活跃资金和市场响应三类证据。
- 只做板块龙头或明确的主升强者，不做无主线的跟风、尾盘补涨、逆势反抽和横向震荡。
- 龙头的发现以盘后复盘为起点，盘中买入必须等待市场确认；二板可作为识别龙头的观察节点，但不是机械“二板必买”。
- 放量、板块共振、资金接力和人气是核心证据；无量的一字板或孤立涨停不能自动定义为龙头。
- 热点退潮、市场确认出现新精神领袖、个股跌破主升结构时果断退出；不要因为别人的盈利或自己的成本而继续持有。
- 只使用 `signal_time` 前数据，下一根可交易K线执行；已涨停后再追认“龙头买点”属于事后判断，必须标记为 `ex_post_label`。

## 研究流程

1. 盘后把当日强势板块、低位放量涨停、连续涨停和关联股响应整理成候选；建立 `theme_id` 与 `leader_rank`，不只看单只股票。
2. 盘中确认：板块是否继续扩散、龙头是否放量/换手/承接、市场成交和情绪是否支持接力。没有主线龙头就 `NO_TRADE`。
3. 只有当龙头仍有可执行价格且处于主升/确认阶段，才输出 `TRIGGERED`；跟风股只能是比较样本，不是替代买点。
4. 将“新题材龙头”“旧题材龙头延续”“龙头退潮/切换”分开回测，不能混成一个收益率。

## 输出格式

```text
data_cutoff / signal_time:
theme: 题材及催化，是否新/是否正在扩散
leader_evidence: 龙头排名、成交量、板块共振、人气/资金响应
stage: 观察 / 主升确认 / 退潮切换 / UNVERIFIED
trigger: 下一可交易窗口的客观确认
invalidation: 失去龙头地位、题材退潮、市场风险扩散等
action: WATCH / TRIGGERED / NO_TRADE
position: 按风险预算给出，不默认满仓
```
