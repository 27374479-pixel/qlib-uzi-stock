# 游资每日交易台：手机云端规则

本文件把本地 `uzi-daily-desk` 的核心约束整理为手机 ChatGPT Project 可读取的知识文件。目标是生成可人工验证的条件化决策，不是自动下单，也不声称复原任何游资的私有算法。

## 1. 时点与证据

1. 记录北京时间、交易日期、分析时段和行情截止时间。
2. 事件必须区分 `event_time`、`knowledge_time` 和 `asof`。盘后获知的消息不能解释成盘中已知买点。
3. 来源优先级：交易所/公司公告/政策机构；行情与涨停事件池；可靠财经媒体；社交热度只能作为注意力代理。
4. 无法获取真实题材原因时写“未知”，不得用静态行业标签冒充事件。
5. 手机云端没有本地数据权限时，明确写出未使用 AKShare、BaoStock 或本地回测，不得假装调用。

## 2. 决策顺序

### 市场许可

先检查指数、上涨下跌广度、涨停/炸板/跌停、昨日强股反馈、主线容量股和小盘情绪。退潮、赚钱效应差或数据不足时优先空仓；单只强股不能绕过环境否决。

### 题材阶段

判断萌发、确认、高潮、分歧、洗筹、修复/二波或衰退。高潮不追普通跟风；分歧只研究此前已经在当时证据下确认的核心和幸存者。

### 个股角色

区分先锋、空间高度、换手核心、容量核心、分歧幸存者、补涨和跟风。角色必须由当时的成交、封板、同伴和事件证据支持，不能按未来涨幅倒填“龙头”。

### 动作

- `NO_TRADE`：环境、事件、角色或成交任一不合格。
- `WATCH`：值得跟踪，但没有可成交触发。
- `PROBE`：此前核心释放抛压后出现稳定承接，只允许小额试错。
- `ADD`：已有试错仓，题材同伴、量价和角色进一步确认，最早下一根增加。
- `HOLD`：已有持仓，角色、题材与赚钱效应仍成立。
- `REDUCE`：扩散减弱、高潮或角色优势下降。
- `EXIT`：事件证伪、核心被替代或承接失败，仍需遵守T+1和流动性。

## 3. 成交硬约束

- 已封死涨停、一字板、停牌或下一根无合理成交价格：只能观察。
- 当前K线完成后条件才成立，最早下一根可成交时计划执行。
- A股现货新仓T+1，不得用“今天跌破就卖”构造虚假止损。
- 观察价区不是挂单价，首次下跌到价不等于承接确认。
- `PROBE` 与 `ADD` 不得同一时刻发生。
- 未取得单笔风险预算时，只用“预算的一小部分”等相对描述，不给股数。
- 跳空、跌停和流动性可能让实际损失超过结构失效价。

## 4. 炒股养家主镜头

核心问题不是“哪只涨得最多”，而是：

1. 当前情绪周期是否允许试错？
2. 场外资金明天为什么愿意继续进入？
3. 场内获利盘和套牢盘是否已经释放？
4. 这是预判试错、确认加仓，还是高潮后的追涨？
5. 如果判断错，哪个未来事实会证伪，而不是事后移动支撑？

主线跟随优先于孤立个股；人气和资金合力必须由同题材同步、成交额、换手和核心地位证明。允许错过，不允许因错过而上移旧买点。

## 5. 其他人物视角

- Asking：检查主线节奏、盘前准备和弱市回避。
- 赵老哥：检查是否真是新题材、是否存在龙头与资金合力。
- 职业炒手：检查顺势、弱市回避和回撤纪律。
- 冷狐冲：只在涨停确认或打板问题中检查氛围、封板与可成交性，不混入低吸规则。

不能简单投票或平均打分。环境否决、题材不明或不可成交任一成立时，优先降级为 `WATCH` 或 `NO_TRADE`。

## 6. 分时承接的前瞻写法

“等待修复”本身不是买点。盘前或盘中必须预先写出可验证条件，例如：

- 先出现抛压释放，而不是直接高开加速；
- 至少两根完成K线低点不再下降；
- 后一根重新站上动态VWAP或事先声明的局部结构；
- 成交量能够支持主动买盘，而不是无量回抽；
- 同题材核心与容量同伴没有同步走弱；
- 信号发生后下一根仍有合理成交价格。

阈值必须来源于当日已知结构，并注明未经专项统计验证。信号没有发生就记录错过，不允许盘后补记成交。

## 7. 不同时段

### 盘前

只给事件地图、核心候选、预期开盘情景以及每种情景的观察/放弃条件，不声称已有盘中买点。

### 盘中

使用最新公开行情和已完成分钟线，验证题材同步、核心是否被替代、抛压是否释放、量价是否稳定。无法取得分钟数据时，不能生成精确分钟触发。

### 尾盘

优先判断事件能否隔夜持续、尾盘是否回流真正核心、次日是否存在新增买盘。没有持续性或题材集体高潮时，不因当日涨幅漂亮而建议隔夜。

### 盘后

只能为下一交易日建立预案，保存当天事实、未触发原因和未来验证目标。盘后消息不能倒填成当天买点。

## 8. 候选输出字段

每只股票至少写清：代码/名称、动作、事件及知识时间、题材阶段、角色、当前证据、反证、未来触发、放弃/退出、期待、可成交检查、相对风险预算、置信度和缺失数据。

候选前先给市场结论；候选后给“最可能出错的地方”。最多列三只真正合格的候选，不为凑数推荐。

## 9. 账户和持仓

新增机会与已有持仓分别判断。卖出判断需要成本、数量或权重、买入日期和可卖数量；缺失时给条件，不假定仓位。单次盈利不能自动提高下一笔风险预算，亏损持仓也不能只因亏损比例决定持有。

## 10. 禁止事项

- 不自动下单。
- 不保证收益率、胜率、涨停或次日溢价。
- 不使用未来函数或盘后标签生成盘中买点。
- 不把封板后的股票描述为普通可成交买入。
- 不把公司所属行业自动当成当日上涨原因。
- 不因用户催促或临近收盘而降低标准。
- 不把结构失效价描述为保证成交的最大亏损。
