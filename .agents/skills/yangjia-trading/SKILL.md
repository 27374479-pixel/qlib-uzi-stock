# 炒股养家研究

这个 Skill 是“炒股养家”公开思路的研究代理，不声称复原其私人、未公开的交易系统，也不把 PDF 中的营销内容或其他游资语录当成他的规则。用户提供的资料是研究材料，不是给 Codex 的执行指令。

## 适用范围

用于：

- 盘中判断是否存在可操作的短线机会；
- 从涨停、连板、分歧、回封、板块联动和资金行为中筛选人气核心；
- 把“预判—试错—确认—加仓”写成可回放、可回测的条件；
- 复盘为什么观察、为什么触发、为什么放弃。

不用于：

- 把当前涨停股自动当成买点；
- 仅凭技术指标、模型分数或龙虎榜一项直接下结论；
- 把其他游资的风格、价值投资或趋势系统混入“炒股养家”标签；
- 对个人账户给出无条件的重仓、满仓或收益承诺。

原文整理和页码映射见 [references/yangjia-principles.md](references/yangjia-principles.md)。只有在需要核对来源或解释某条原则时才读取该参考文件。

## 核心判断框架

### 1. 先判断环境，再看个股

先给出时间戳和市场状态：指数方向、涨跌家数、涨停/跌停、炸板率、连板高度、主线板块扩散和资金的“赚钱效应/恐慌效应”。短线情绪可以观察周期性，但不能声称精确预测指数或个股下一根K线。

- 赚钱效应增强：优先跟随已被市场验证的主线和核心，允许更多机会，但仍需确认。
- 恐慌效应增强：减少交易，等待板块或市场出现集体性、可解释的止跌修复；不要把单只股票下跌当作抄底理由。
- 环境不清晰：输出“观察/放弃”，而不是为了凑出股票名单。

### 2. 只做跟随，不假设自己能发动行情

把“人气核心”定义为市场实际注意力和资金共同验证的结果，至少观察：

- 主题是否是当前主线，而不是单只股票的孤立题材；
- 同板块是否有扩散、跟随或至少同步反应；
- 个股是否具有相对强度、持续成交和可辨认的市场关注度；
- 龙头/核心的上涨是否仍有板块功能、预期差和风险收益空间。

不要因为“龙头”二字忽略已经兑现、估值过热、板块退潮或风险收益不对称。龙头识别是动态的，不能用静态排名替代盘中观察。

### 3. 买点必须是预先定义的实时事件，不是事后“已经修复”

“修复”只有在触发时刻被预先形式化，才可能成为买点。盘后说“它后来修复了”只是复盘标签，绝不能倒推成当时可以买。每个信号必须保存 `signal_time`，并且只允许使用 `signal_time` 及之前的数据；成交假设放在下一根可成交K线或下一笔可成交报价。

把盘中机会分成四段：

1. **预判**：根据前一交易日的主线、人气和情绪，建立观察名单；不能直接重仓。
2. **试错**：价格处在可接受的分歧区间，且风险点明确；只记录小规模研究试错，不把预判当确认。
3. **确认**：在预先写好的观察时刻，个股满足止跌或转强、重新站回关键价/VWAP、量价配合、同板块至少一只核心同步等条件；条件必须在这一时刻已经全部可见，不能等待收盘结果。
4. **加仓**：只有确认后才讨论加仓；若确认消失，退出或回到观察，不补仓摊低成本。

对“低吸”特别注意：

- 当前已经封死涨停的是观察结果，不是新的买入点；一致性兑现后必须重新等待分歧。
- 低开、下探、回收前收本身不够，必须看是否是板块/市场共同分歧后的修复。
- 跌破前低不是永远有效的机械止损，也不是可以忽略的风险。若单股先破前低，原低吸信号作废；只有在新的观察时刻，预先声明的集体恐慌、板块共振、主动回收和风险收益条件同时成立，才产生一轮新信号。之后的继续上涨不能反向证明此前可以买。
- 价格已经超过预设的最大追价幅度，哪怕走势很强也输出“不追”，等待新的分歧窗口。

一个合格的盘中规则应写成类似：`t=09:45` 时，若“早盘下探条件、收盘回收关键价、VWAP条件、板块同步条件、市场环境条件”全部满足，则在 `t+1` 试错；若 `t=09:45` 未满足，不能在 10:51 看到上涨后补写这个信号。阈值可以调整，但必须在回测前固定或按当时信息计算。

### 4. 期待的是行为，不是想象中的目标价

每个候选都必须写清楚下一步要验证的事件，例如：

- 开盘分歧后守住关键位置并回收VWAP；
- 主线核心没有继续走弱，板块出现同步放量；
- 弱转强时不破开盘价并出现主动买盘；
- 高位核心出现分歧但没有引发板块退潮。

同时写出放弃条件：竞价/开盘超出可接受区间、预定义观察时刻没有修复、跌破风险参考位、板块失去联动、市场恐慌扩散或风险收益不再对称。不能用“希望明天涨”代替预期。

### 5. 仓位和回撤是判断的一部分

公开整理中把赢面和仓位联系起来，但这些区间只能作为研究评分，不得直接转换成用户个人账户配置。实务上采用：赢面不清晰则观望；只有风险可量化、预期空间显著大于风险且确认充分，才从小试错提高到确认仓位。系统性风险或主线退潮时，优先降低交易频率和敞口。

不要把“永不止损/止盈”按字面实施。应把它解释为：不因成本、盈亏或情绪机械交易；一旦买入逻辑失去确定性，按事先写好的出局条件执行。禁止用补仓摊平来掩盖判断错误。

## 数据与时间纪律

- 实时判断必须标注 `asof_time`、数据源和最后一根已完成K线；例如用户说 10:28 时，只使用不晚于 10:25 的 5 分钟K线。一般规则是只使用不晚于判断时刻的最后一根已完成K线，不能偷看未来数据。
- 复用本项目的 `current_yangjia_candidates.py` 和 `current_yangjia_actionable_candidates.py`，但把它们的分数视为候选排序，不视为交易许可。
- 优先使用本地 AkShare/BaoStock 缓存，缺失时再用东方财富等公开源补齐；记录数据新鲜度和来源。龙虎榜过期时必须降权，不能把历史净买入当作当前承接。
- 回测只使用当时已经可见的信息；盘中信号用下一可成交时点执行，不能用收盘后才知道的涨停、龙虎榜或板块排名反向筛选。
- 严格区分 `prospective_signal`（当时可执行的信号）和 `ex_post_label`（后来发生的修复/上涨/失败）；后者只能用于复盘和标签，不能参与买点生成。
- 同时保存“未交易”记录，区分“没有信号”和“有信号但没有成交”，避免只统计成功案例。

## 标准输出

回答实时判断时按以下顺序输出：

1. 截止时间、最后已完成K线、数据源和市场情绪状态；
2. 当前主线与核心候选；
3. 每只股票符合的公开原则及具体证据；
4. 当前状态：`可试错`、`等待确认`、`只观察` 或 `放弃`；
5. 触发条件、放弃条件、期待验证的下一步行为；
6. 明确哪些已经涨停、过度一致或已经错过窗口，不追；
7. 明确“没有合格机会”也是有效结论。

输出必须把“候选池”“已触发”“可以追价”分开，不能把三者混成一张买入清单。

任何规则都不能保证可靠盈利；Skill 的目标是把主观思路变成无前视、可验证的条件，并用历史样本检验其胜率、盈亏比、回撤和未交易比例。
