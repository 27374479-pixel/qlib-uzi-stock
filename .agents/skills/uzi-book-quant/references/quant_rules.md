# 两册心得的量化映射

这是研究用的公开思想代理，不声称复原任何人的真实账户策略。

## 可观测层

- 环境：前一完整交易日涨跌广度、赚钱效应/涨停质量、近5日状态；当前截止时刻广度、涨跌幅中位数和炸板代理。
- 主线：首选点时事件原因/概念中的群体数量、首次异动、封板/炸板、延续和量能；缺失时才用点时行业快照，而且必须标记“行业代理”。历史实证已显示静态行业共振不能稳定替代真实题材。
- 核心：全市场和群体内的涨幅分位、过去10日强度、从日内高点回撤后的修复、截止时刻量能分位。
- 触发：右侧主线确认、强势回撤后重新转强、炸板/近板换手后的再确认、极弱环境中指数与主线同步转稳的低仓反弹。
- 风险：一字板不可成交；连续追高、群体退潮、市场高潮炸板扩散和个股失去承接时放弃或退出。

## 不可直接量化的部分

新闻真假、题材级别、盘感、席位协同、订单簿排队和临盘理解力无法由普通5分钟OHLCV完整表达。使用行业/概念或炸板代理时必须写明缺失，不能把代理结果表述成“已经识别真实主线”。

## 预先声明的仓位思路

环境只影响风险预算，不改变成交规则：强势约0.60、震荡约0.35、退潮约0.12、高潮约0.20，冰点为0；只有市场、群体和核心同步转稳时，冰点反弹才给小仓位。具体数值若要修改，必须在开发段预先声明并用样本外冻结验证。

“预判试错、确认加仓”应显式建模，例如先为候选槽位投入约1/3，后续出现可观察的承接/收回且下一根可成交时再投入余下仓位。未确认的现金收益记为0，不能把小仓交易收益放大成满仓收益。比例只是待验证配置，不是作者原始参数。

## 可复核的交易状态机

`新事件出现（观察） -> 题材延续/分歧 -> 核心或幸存者排序 -> 小仓试错 -> 下一根成交 -> 确认后下一根加仓 -> T+1后弱势退出/强势有限延续`。

固定 horizon（T+1/T+2/T+5）只用于诊断；动态退出规则必须在入场前写死，不能从未来最高价、最低价或最优卖点反推。对每笔交易保存信号时间、成交时间、成交状态、退出理由和缺失数据原因。

## 已证伪的便捷替代

- 固定六个钟点扫描“行业涨幅第一”不能代表事件驱动，也不能代表炒股养家的可执行买点。
- 当日收盘封板后无条件次日追“确认核心”，在本项目长样本中没有稳定优势；它只能作为待观察事件。
- 收盘封板必须与一字板区分；“全天最低价也在涨停价”只是一字板口径，不是普通封板口径。
- 盘中新仓失败后按当日价格止损违反A股T+1，必须承担到下一可卖时点的风险。
