# 职业炒手交易

用于把“交易的本质”落成前瞻性的短线判断，而不是把事后上涨解释成买点。语料来自用户提供的《48位游资悟道心得语录》第二章，是公开二次整理，不能视为本人认证的完整私有系统。

## 核心边界

- 先判断市场环境，再判断板块和个股；弱市默认少做或不做，不能为了有股票可选而降低门槛。
- 把顺势理解为跟随已经被资金和市场验证的方向，不预测指数或个股下一步一定怎么走，不把“便宜”当安全。
- 以稳定复利和回撤控制为目标；单笔机会必须先写失效条件和退出路径，再讨论收益空间。
- 只使用 `signal_time` 之前可见的数据，保存 `data_cutoff`；回测在下一根可交易K线执行，严禁用后续修复、涨停或收盘结果反推买点。
- 当前已经封死涨停的股票不能直接当作本 skill 的新买点；只能作为“已发生的验证样本”或次日观察对象。

## 工作方式

1. 先给市场状态：指数方向、上涨/下跌家数、涨停/跌停及连板晋级、成交额和主线是否收敛。数据缺失就标记 `UNVERIFIED`，不补猜。
2. 再给候选：只在主线或强势板块中找相对强、成交活跃、趋势尚未被破坏的标的。把“强势回踩承接”和“趋势确认后的跟随”分开记录，不把两者混成低吸。
3. 输出 `WATCH`、`TRIGGERED` 或 `NO_TRADE`。每个 `TRIGGERED` 必须同时列出触发价/触发事件、执行时间、止损或退出条件、预期持有周期和仓位上限。
4. 若市场处于明显下跌通道，仅允许把极端超跌反弹列为观察，且必须有市场止跌、板块回流、个股承接三层确认；没有三层确认就放弃。
5. 盘后复盘只用于形成下一交易日的候选和假设，不能把盘后看到的涨幅写成当天可执行信号。

## 输出格式

```text
data_cutoff / signal_time:
market_regime: 顺势 / 震荡 / 风险收缩 / UNVERIFIED
candidate:
  thesis: 为什么它属于当前被资金验证的方向
  trigger: 下一根K线前可观察的客观条件
  invalidation: 哪个条件出现就放弃或退出
  action: WATCH / TRIGGERED / NO_TRADE
  position: 仅给风险预算，不默认满仓
evidence: 只列 signal_time 前的证据
```
