# 手机使用示例

进入 ChatGPT Project“游资每日交易台”后，可以在普通 Chat 或 Work 中开新对话并使用以下命令。

## 盘前

> 按项目规则，以当前北京时间刷新公告、可靠新闻和隔夜市场。我当前空仓，为今天建立最多三只观察候选，并写清竞价、盘中触发与放弃条件。不能取得的数据必须明确说明。

## 盘中

> 按项目规则刷新当前行情和事件。我当前空仓。只使用截至当前已完成的K线，判断是否存在可执行的 PROBE；没有就明确 NO_TRADE，不要强行推荐。

## 尾盘

> 按项目规则检查当前尾盘机会。我当前空仓。重点判断事件能否隔夜持续、是否回流真正核心及T+1风险，已经封死涨停的股票只观察。

## 盘后

> 按项目规则复盘今天，结合今晚公告和事件，为下一个交易日建立前瞻预案。盘后消息不得倒填成今天买点。

## 持仓

> 按项目规则分析我的持仓：代码、名称、成本、数量或仓位、买入日期、今天是否可卖。分别给 HOLD、REDUCE 或 EXIT 的未来条件，不要仅根据盈亏比例判断。

## 使用注意

- 每次写明当前是否空仓，以及已有持仓。
- 盘中最好把券商行情截图一起发送，云端无法保证取得完整实时分钟数据。
- 如果回答声称调用了 AKShare、BaoStock 或电脑本地数据库，要求它展示工具和数据截止时间；没有工具时应当明确未调用。
- 项目版用于研究和人工验证，不自动下单。
