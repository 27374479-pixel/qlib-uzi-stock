# 炒股养家公开资料整理

## 来源边界

本文件只整理用户提供的《48位游资-上册.pdf》中“第一章 炒股养家：洞悉情绪周期”部分，即 PDF 第 50–69 页，对应书内页码约 1–20。该 PDF 是公开语录/二次整理，不能当作炒股养家本人发布的完整、可验证的交易系统；书中其他章节和其他人物的内容不纳入本 Skill。

以下是转述和操作映射，不是长段逐字摘录。

## 主题索引

### PDF 第 51–54 页：交易本质与情绪周期

- 超短本质被描述为群体博弈：场外潜在买入者和场内卖出倾向的变化，决定当下买卖力量。
- 买入/卖出倾向不是单看一只股票，而要结合大盘、主流热点和盘中动态判断。
- 情绪周期来自持币者与持筹者的博弈：失望、恐慌、资金回流、强化可以循环，但循环不是精确预测器。
- 核心思想是基于市场情绪评估风险收益，而不是把技术指标当作唯一答案。
- “龙头”需要市场关注、带动性、板块功能和预期空间；龙头称号不能靠静态标签永久获得。

**量化代理**：涨跌家数、涨停/跌停、炸板、连板高度、主线扩散、板块同步率、指数/板块相对强度、成交量变化、VWAP修复。

### PDF 第 55–58 页：赢面、回撤和分歧

- 公开整理把赢面与仓位分层，核心不是固定百分比，而是只有在风险收益显著偏向自己时才提高仓位。
- 机会多时多做，机会少时少做；控制系统性崩溃风险比预测每一次波动更重要。
- 连续下挫后的集体性恐慌，比一只股票孤立下跌更接近可研究的超跌窗口。
- 强势阶段强调资金赚钱效应，弱势阶段强调恐慌效应和防守；同一价格形态在两种环境中不能用同一仓位解释。
- 卖出应围绕不确定性和环境变化，不围绕成本价执念。

**量化代理**：市场宽度、板块集体跌幅、个股与板块的相对跌幅、连续下跌后的放量、修复成功率、候选的预期空间/风险空间比。

### PDF 第 59–61 页：赚钱效应、恐慌效应和跟随

- 赚钱效应增强时，资金更容易形成持续热点；追涨行为过度、强势股失去跟随时，往往会转向补跌。
- 要根据赚钱效应和恐慌效应在追涨与超跌之间切换，而不是永远只做一种模式。
- 交易者定位是“跟随更紧”，不是假设自己能够发动市场。
- 大局观高于单个技术指标；成交量重要，但必须结合价格、市场内外人心和板块状态。

**量化代理**：主线近 3/5 日扩散、核心与跟风的强弱差、炸板后的修复、量价背离、板块中位数表现、板块内至少一只核心的同步确认。

### PDF 第 62–65 页：预判、试错、确认、加仓与简化

- 交易理念被整理为“预判、试错、确认、加仓”等阶段，判断不应停留在预测，而要观察市场反馈。
- 对突破、技术图形和指标保持克制；实际量价和市场反应优先。
- 追涨与超跌的切换取决于资金效应和恐慌效应，不取决于单个固定形态。
- 买入后若仍被成本、补仓或止损念头绑架，说明交易逻辑不够清楚；更简单的选择是继续持有、换股或退出，而不是摊低成本。
- 庄家叙事不应替代全局判断；政策、技术、基本面、资金和人气的共振比单一解释可靠。

**量化代理**：信号阶段字段、确认后的成交执行、失败后的退出、禁止补仓、板块共振分数、信息新鲜度。

### PDF 第 66–69 页：现金账户检验与职业化

- 判断持仓时可以做“如果现在是空仓，我会不会买它”的反事实检验；若不会，应考虑退出或换股。
- 提高视角、选择机会而非沉迷止损点，操作应尽量简单；但简单不等于没有风险控制。
- 新手建议关注各周期领涨和领跌品种、观察板块趋势，不要沉迷某个指标或一条资金流数据。
- 稳定性和回撤控制比偶尔的大盈利更重要，长期结果取决于持续学习、复盘和适应市场。

**量化代理**：空仓反事实字段、主线/领涨/领跌榜、候选与板块趋势、策略回撤、连续亏损后的降频规则。

## 从原文到程序的注意事项

1. 不把“龙头”“低吸”“大局观”直接当成布尔字段；先定义可观察证据和当时可获得的数据。
2. 不把“别人贪婪/恐惧时反向操作”机械化；先判断赚钱效应或恐慌效应是否已经在板块层面形成。
3. 不把“跌破前低”单独当作永远有效或永远无效；区分原信号失败和新一轮集体恐慌后的重新确认。
4. 不把 PDF 中的赢面、仓位或收益描述当成回测结果；需要用本地历史数据、交易成本、滑点和未交易样本独立验证。
5. 任何当前判断都必须保存知识截止时间，不能用收盘后数据解释盘中买点。
