# 冷狐冲：盘感训练及打板技术

用于研究“什么样的涨停值得参与、何时确认、何时放弃”，同时把盘感落成可回放和可回测的字段。材料来自用户提供的《48位游资悟道心得语录》第五章，是公开二次整理，不能视为本人认证的完整系统。

## 核心边界

- 打板不是看到涨停就买；先判断市场氛围、板块攻击强度、个股人气/股性和趋势，再决定是否等待封板确认。
- 复盘用于训练识别和形成次日假设，盘感不能成为事后解释；每个信号必须有时间戳和当时可见证据。
- 只使用 `signal_time` 前数据，模拟下一根可交易K线；已封死涨停后才发现的股票不能当作可复现买点。
- 弱市对打板要求更高，尤其要警惕半路、冷门板和低质量接力；高位板必须有足够的市场氛围与风险预算。
- 所有输出必须明确 `WATCH`、`TRIGGERED` 或 `NO_TRADE`；没有至少约定的把握度/合力证据时不交易。

## 研究流程

1. 盘前/盘后复盘涨跌停、连板、快速涨幅、近期活跃板块、板块指数和龙头；每天保留可解释的少量候选。
2. 盘中先看市场氛围，再看板块强度和人气股表现，最后看个股K线、成交量、启动时机和回落承接。
3. 按把握度分层：高把握可在启动确认时观察；中把握等待冲板并看合力；低把握只看不打。把握度是研究标签，不能用收益结果倒填。
4. 一板、二板、三板及高位板分层统计；弱势/强势市场分别回测，不能用强市打板收益覆盖弱市风险。
5. 对炸板、封板失败、次日不及预期和市场尾盘转弱建立退出与放弃标签；回测必须计入滑点、排队无法成交和涨停开板风险。

## 输出格式

```text
data_cutoff / signal_time:
market_atmosphere: 强 / 中性 / 弱 / UNVERIFIED
board_stage: 首板 / 二板 / 高位接力 / 非涨停观察
confluence: 市场氛围、板块攻击、个股人气/股性、趋势/成交量
confidence: high / medium / low
trigger: 仍可执行的点火、冲板或封板确认条件
invalidation: 炸板、板块不跟、市场退潮、承接失败等
action: WATCH / TRIGGERED / NO_TRADE
position: 按风险预算，不默认满仓
```
