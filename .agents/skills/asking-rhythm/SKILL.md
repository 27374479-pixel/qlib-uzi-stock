# Asking：超短节奏把握

用于研究“何时做、做什么、何时不做”的超短节奏。材料来自用户提供的《48位游资悟道心得语录》第三章，是公开二次整理，不等同于可复制的私人账户规则。

## 核心边界

- 只跟随已经出现的市场行为，不预测市场和个股；盘前计划是条件假设，盘中必须等市场确认。
- 热点、板块强度、龙头表现和成交量优先于复杂指标；候选从强势板块中产生。
- 早盘和尾盘是主要观察窗口，午盘少做；但“时间段”不是单独买点，仍需主线和合力确认。
- 弱市原则优先级最高：指数下行、跌停扩散或题材快速切换时，宁可空仓；极端超跌反弹必须单独验证。
- 只使用 `signal_time` 之前的数据，回测在下一根可交易K线成交；任何盘后修复不能补写买点。已经涨停的股票不能因为“涨停了”才追认成早盘信号。

## 研究流程

1. 盘前/盘后形成少量强势板块和龙头候选，写清楚明天需要看到什么才行动；不要把全市场扫描结果当作信号。
2. 盘中先判断市场风格和板块合力，再看个股是否是热点中的强者。把“追涨确认”和“龙头回踩低吸”分别回测。
3. 追涨模式要求热点首次放量、强势突破或涨停确认前仍有可执行价格；低吸模式要求龙头仍在趋势内、回踩有承接，不能在下跌通道盲猜底。
4. 输出 `WATCH`、`TRIGGERED` 或 `NO_TRADE`，同时给出信号时间、执行窗口、失效条件、预计持有周期和仓位。
5. 收盘复盘重点看少量代表性股票、公告、热点和涨停结构，形成下一交易日的条件单；不使用当天收盘后的信息模拟当天成交。

## 输出格式

```text
data_cutoff / signal_time:
market_regime: 强 / 中性 / 弱 / UNVERIFIED
mode: trend-chase / leader-pullback / oversold-rebound / NO_TRADE
candidate:
  why_now: 当前市场行为如何确认它
  trigger: 仍可在下一可交易窗口观察的客观条件
  invalidation: 失去板块或个股强度时的退出/放弃条件
  action: WATCH / TRIGGERED / NO_TRADE
  position: 风险预算，不默认满仓
evidence: 不得使用 signal_time 后的数据
```
